# 🐍 Python + Banco de Dados (IDEP)

## 📌 Descrição
Este repositório contém a implementação prática da integração do **Python** com banco de dados, utilizando a base de dados do **IDEP** como exemplo.  
O objetivo é aprender a **conectar, consultar e extrair informações** diretamente do banco, manipulando os resultados por meio de scripts em Python.  

---

## 🎯 Objetivos da Prática
- Compreender como o Python se conecta a um banco de dados.  
- Realizar consultas SQL diretamente a partir do Python.  
- Extrair e visualizar informações da base do IDEP.  
- Aplicar os conceitos de integração entre **linguagem de programação** e **SGBD**.  

---

## ⚙️ Tecnologias Utilizadas
- **Python 3.x**  
- **Biblioteca [mysql-connector-python]** ou **pymysql** (dependendo da configuração)  
- **Banco de Dados MariaDB/MySQL** (via **phpMyAdmin** ou **DBeaver**)  
- Base de dados: **IDEP**
